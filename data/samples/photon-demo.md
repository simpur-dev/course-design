# 数据库顶会示例 · Photon (SIGMOD 2022)

Photon is a vectorized query engine for Lakehouse environments and supports the Apache Spark API [@behm2022].

Photon is written in C++ and uses vectorized interpretation instead of code generation [@behm2022].

Photon has accelerated some customer workloads by over 10× [@behm2022].

Photon set a new audited 100TB TPC-DS benchmark record [@behm2022].

Photon set a new audited 500TB TPC-DS benchmark record [@behm2022].
